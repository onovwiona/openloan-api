🎯 Customer Onboarding & Authentication

New customer registration, login, and initial profile setup

1
User Registration
Customer
POST /api/v1/register
Request Payload:
{ "first_name": "John", "last_name": "Doe", "email": "john.doe@example.com", "phone": "+1234567890", "password": "securepassword123", "password_confirmation": "securepassword123" }
✅ Success Response (201): { "success": true, "message": "User registered successfully", "data": { "user": { "id": "uuid-here", "first_name": "John", "last_name": "Doe", "email": "john.doe@example.com", "phone": "+1234567890", "roles": [{"name": "customer"}] }, "access_token": "jwt-token-here", "token_type": "bearer", "expires_in": 3600 } }
2
User Login
Customer
POST /api/v1/login
Request Payload:
{ "email": "john.doe@example.com", "password": "securepassword123" }
✅ Success Response: { "success": true, "message": "Login successful", "data": { "user": { "id": "uuid-here", "first_name": "John", "last_name": "Doe", "email": "john.doe@example.com", "phone": "+1234567890", "roles": [{"name": "customer"}] }, "access_token": "jwt-token-here", "token_type": "bearer", "expires_in": 3600 } }

Use the access_token in the Authorization: Bearer {token} header for all subsequent requests.
